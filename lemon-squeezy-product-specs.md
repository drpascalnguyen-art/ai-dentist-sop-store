## How To Create Each Product In Lemon Squeezy

1. Dashboard → Products → New Product
2. Type: Digital (file download)
3. Paste the Title, Price, and Description from the spec below.
4. Upload the deliverable file listed under "Deliverable."
5. Set status to Draft. Pascal approves each before publishing.
6. After publishing, copy the `/checkout/buy/...` link and paste it into `commerce-links.md`.
